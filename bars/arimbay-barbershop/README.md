Arimbay Best Barbershop

Run locally
1. Unzip the folder.
2. Open index.html in any modern browser, or run `python3 -m http.server 8000` in the folder and visit http://localhost:8000.

Add your media
- Portrait video: save as assets/portrait.mp4 (the HTML already points to it).
- Photos: search index.html for "REPLACE PHOTO HERE" and add <img src="assets/your-photo.jpg" alt="..."> at each spot.
- Service photos: add these files to `assets/`: `classic-haircut.jpg`, `skin-fade.jpg`, `beard-sculpt.jpg`, `hot-towel-shave.jpg`, `haircut-beard-combo.jpg`, and `kids-cut.jpg`. Each service card already points to its matching file.
- Hairstylist photos: add four images named `hairstylist-1.jpg` through `hairstylist-4.jpg` in `assets/`. They appear on the public home page and in the booking barber selector for Rico, Jun, Marco, and Ian, in that order.

Accounts
- Admin: admin@arimbay.com / admin123
- Clients: create an account on the sign-up tab.

Data is stored in the browser (localStorage). Clear site data to reset.
